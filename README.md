# AI Anti-Counterfeit Solution 발표 데모

Node.js 24에서 아래 명령으로 두 버전을 한 서버에서 실행합니다.

```sh
npm ci
npm run dev
```

- [발표 시작 · 이전 버전](http://127.0.0.1:4173/before)
- [최신 버전](http://127.0.0.1:4173/after)

## 5분 발표 대본

- [영어·한국어 통합 대본](docs/peer-feedback-presentation.md)

상단 링크로 버전을 전환합니다. 같은 탭에서 전환하거나 브라우저의 뒤로 가기·앞으로 가기를 사용하면 각 버전에서 선택한 케이스와 입력 내용이 유지됩니다. 새로고침하면 해당 URL의 버전이 초기 상태로 열립니다.

상단의 **변경점 표시**를 켜면 4조 피드백 목록과 화면 속 빨간 번호가 나타납니다. 목록에서 항목을 펼치고 **화면에서 보기**를 누르면 해당 위치로 이동합니다. 빨간 번호나 테두리에서도 같은 설명을 열 수 있습니다. **변경 목록**을 누르면 목록이 다시 열리고, 표시 상태는 같은 탭에서 버전을 바꿔도 유지됩니다.

최신 버전은 고위험·재판매·자료 누락을 포함한 다섯 가지 합성 사례를 제공합니다. **예시 AI 결과 보기**를 누르면 사례별로 미리 준비한 결과가 열립니다. 근거 검토·선택, 초안 갱신, 담당자 결정 기록은 페이지에서 시연할 수 있습니다.

이전 버전에는 원래의 Gemini 실험 화면이 있습니다. 그 기능을 시연하려면 프로젝트 루트의 `.env`에 `GEMINI_API_KEY`를 설정한 뒤 서버를 다시 시작합니다.

이미 빌드한 상태에서는 `npm start`로 바로 실행합니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.
